# 图片查看、保存与参考图生成设计

## 目标

让画布中的图片始终完整可见，支持查看原图、缩放与保存到本地，并允许用户从当前项目选择一张图片作为 ChatGPT 生图参考图。参考图会真正上传到 ChatGPT，而不是只记录界面关系。

## 交互设计

- 画布节点与右侧详情预览使用 `contain`，保持图片完整比例，并以深色中性底承接留白。
- 点击详情预览或“查看原图”打开全屏查看器。默认适应窗口，支持放大、缩小、恢复适应、鼠标滚轮缩放、拖拽平移和 Esc 关闭。
- 详情面板提供“保存原图”按钮。桌面版使用系统“另存为”对话框；普通浏览器使用下载回退。
- ChatGPT 生图面板新增“参考图片”区域：可使用当前画布已选图片，也可从当前项目图片列表选择一张；可以移除和替换。
- 发送任务时，将参考图片 ID 同时写入生成任务的 `parent_image_id`，并由桌面进程读取本地图片、附加到 ChatGPT 输入框，确认附件就绪后再发送 Prompt。
- 新生成图片继续由现有导入流程保存，并自动建立参考图到生成图的父子版本连线。

## 技术设计

- 前端新增复用型图片查看器和下载工具，并扩展桌面桥接的保存方法。
- 桌面端新增安全的保存 IPC：只接受当前后端媒体 URL，下载后通过系统保存对话框写入用户选择的位置。
- 后端新增按图片 ID 获取单张图片元数据的接口，桌面端通过本地后端读取参考图片内容。
- ChatGPT 自动化在提交 Prompt 前查找文件输入控件；通过 Electron/Chromium 能力附加本地临时文件，等待附件预览出现后再执行原有 Prompt 提交流程；临时文件在任务结束时清理。
- 当前数据模型维持单一 `parent_id`。接口命名保留扩展空间，未来可增加多参考图关联表，而不破坏版本主链。

## 状态与错误处理

- 图片加载失败时继续展示文件名占位，不打开查看器。
- 保存取消不显示错误；下载或写入失败显示明确错误。
- 参考图不存在、不是当前项目图片、下载失败、附件控件缺失或附件等待超时，均停止任务并给出可恢复错误；不会退化为不带参考图的生成。
- 参考图上传期间显示“正在上传参考图”，完成后才切换到“正在发送 Prompt”。

## 验收标准

1. 横图与竖图在画布节点和详情面板中均完整显示。
2. 原图查看器支持适应、25%–400% 缩放、平移与关闭。
3. 桌面版可通过系统对话框保存原始图片文件。
4. 可选一张项目图片作为参考，任务请求携带其 ID。
5. ChatGPT 页面实际出现参考图附件后才发送 Prompt。
6. 生成结果导入画布并与参考图形成父子关系。
7. 新增行为有前端、桌面端和后端自动化测试覆盖。
