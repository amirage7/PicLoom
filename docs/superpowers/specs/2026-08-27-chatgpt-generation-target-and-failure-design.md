# ChatGPT 生图：目标项目与失败反馈设计

## 目标

让 ChatGPT 生图任务始终明确显示其最终导入位置，并在 ChatGPT 拒绝、限流或流程出错时结束“正在生成”状态，展示可理解且可操作的失败原因。

## 范围

- 右侧 ChatGPT 生图面板新增“保存到”项目选择器。
- 选择器列出所有现有项目及“快速创作（未归档图片）”。
- 创建任务时，把选择器当前值作为任务的 `projectId`；快速创作传递 `null`。
- 任务启动后，面板显示该任务的目标位置，并禁止改变目标，直到任务进入终态。
- 用户在任务进行中切换左侧项目，不改变任务的目标项目、任务归属或右侧显示。
- 面板接收终态事件后，以状态、文本和颜色共同说明成功、拒绝、限流、页面变化、取消及一般失败。

## 交互与状态

### 目标项目

1. 面板首次打开时，默认目标为当前工作区：当前项目或快速创作。
2. 空闲时，用户可用标准下拉选择任意项目或快速创作。
3. 点击“使用 ChatGPT 生成”时，前端以该选择值创建后端任务并启动桌面编排器。
4. 创建后，将任务目标保存在生成状态中。即使右侧面板因工作区切换重新渲染，也以任务快照显示相同的目标名称。
5. 任务处于非终态时，下拉控件禁用并附带清晰的当前目标标签；任务结束后可再次选择目标。

### 失败反馈

- `refused`：显示“生成被 ChatGPT 拒绝”，正文优先显示页面适配器捕获的拒绝原因；若原文缺失，使用“ChatGPT 未生成图片，可能因内容限制或请求未完成。”
- `rate_limited`：显示额度或频率受限的说明，并保留合适的重试路径。
- `page_changed`：说明页面结构或登录状态变化，保留“重试收集图片”。
- `failed`：显示桌面编排器、下载、导入或超时产生的具体错误文本；保持可恢复任务的重试路径。
- `cancelled`：显示已取消，且不再显示进行中状态。

终态状态不再使用“正在生成”的视觉语义；错误区使用既有危险色、错误图标和 `role="alert"`，状态区仍保留最新事件文本。

## 数据流

`ChatGptGenerationPanel` 管理空闲时的目标选择，并从应用项目列表解析项目名。开始生成时，它将选择值传给 `createGenerationTask` 与桌面桥接。`generationStore` 维护进行中或可恢复任务的目标项目 ID，使工作区切换不影响展示。桌面编排器继续以请求中的 `projectId` 调用后端批量导入，因此实际导入位置与界面目标保持一致。

## 测试

- 默认目标与当前工作区一致，且快速创作可选。
- 更改下拉项后，创建任务与桌面桥接收到相同目标项目。
- 进行中切换活动项目不会改变任务调用与面板目标显示，且选择器不可编辑。
- `refused`、`failed`、`rate_limited`、`page_changed`、`cancelled` 均不会保留“正在生成”文案；拒绝原因在警示区域可见。
- 现有引用图片、重试收集和任务互斥行为保持不变。
